# NexaTech - Site Institucional

Projeto acadêmico de Front-end desenvolvido com HTML5 e CSS3.

## Páginas
- Início
- Sobre Nós
- Serviços
- Cases
- Contato

## Requisitos aplicados
- CSS externo (`style.css`)
- HTML5 semântico
- Mobile-first
- Media Queries
- CSS Grid e Flexbox
- Tipografia responsiva com `rem` e `clamp()`
- Contraste, labels e navegação semântica
- Hover e transições

## Como executar
Abra `index.html` em um navegador ou utilize a extensão Live Server no VS Code.
